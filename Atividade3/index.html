Autenticação OAuth, JWT e Proteção contra XSS/CSRF

Introdução

Com o crescimento das aplicações web modernas, garantir a segurança e a privacidade dos usuários se tornou essencial. Este trabalho resume os principais mecanismos usados hoje para autenticar e proteger usuários na internet: o protocolo OAuth 2.0, os tokens JWT e as defesas contra os ataques de XSS e CSRF.

OAuth 2.0

O OAuth 2.0 é um protocolo de autorização que permite que aplicações acessem recursos de um usuário sem precisar da senha dele. A versão mais recente das boas práticas (RFC 9700) recomenda:

  • Uso obrigatório do PKCE nos fluxos de login
  • Não usar mais os fluxos "implícito" e de senha, considerados inseguros
  • Validar corretamente as URLs de redirecionamento

JWT (JSON Web Token)

O JWT é um formato de token usado para autenticação sem precisar guardar sessão no servidor. Ele é dividido em três partes: cabeçalho, dados (payload) e assinatura.

  • Cuidado: tokens JWT mal configurados podem ser falsificados, por isso é importante usar algoritmos seguros, definir tempo de expiração e nunca aceitar tokens sem assinatura.

XSS (Cross-Site Scripting)

O XSS acontece quando um atacante consegue injetar código JavaScript malicioso em uma página web. Existem três tipos principais:

  • Refletido
  • Armazenado
  • Baseado em DOM

A principal forma de evitar é sempre codificar corretamente os dados exibidos na tela e usar recursos extras como Content Security Policy (CSP) e cookies com o atributo HttpOnly.

CSRF (Cross-Site Request Forgery)

No CSRF, o atacante engana o navegador do usuário para que ele envie uma requisição indesejada a um site onde ele já está logado, usando os cookies de sessão sem o usuário perceber.

  • Uso de tokens CSRF nas requisições
  • Atributo SameSite nos cookies
  • Verificação da origem da requisição

Conclusão

Não existe uma única solução "mágica" para proteger uma aplicação web. É preciso combinar boas práticas de OAuth, cuidado na implementação de JWT e proteções específicas contra XSS e CSRF, formando várias camadas de defesa.
